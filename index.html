Petunjuk Penggunaan

1. Mode Berlatih

Digunakan untuk latihan soal mandiri. Anda dapat memilih jawaban dan berpindah antar soal dengan bebas.

2. Mode Bermain

Ujian / Tantangan kuis interaktif. Semua hasil pengerjaan, skor, serta rincian jawaban akan secara otomatis tersimpan di database Google Sheets Guru.

3. Integrasi Database

Aplikasi ini terhubung langsung dengan Google Apps Script Web App tanpa memerlukan server tambahan.
